# Audio profesional Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Voz limpia automática (DeepFilterNet, -14 LUFS) en el pipeline, música de fondo con ducking desde `media/music/`, y control de volumen final del render.

**Architecture:** Paso Python `pipeline/audio_clean.py` (adaptado de video-cleanup, MIT) entre normalizar y transcribir; reemplaza el audio de `public/NOMBRE.mp4` y guarda el original en `public/NOMBRE.raw.wav`. Campo `plan.music` + función pura `musicVolume` en TS para el ducking dentro de Remotion. `render.js` copia la pista, admite `--no-music` y corrige el volumen final con `pipeline/final_loudness.py`.

**Tech Stack:** Python 3.13 (.venv, numpy 2.5.4, pytest), ffmpeg, DeepFilterNet CLI 0.5.6, TypeScript/Remotion 4.0.543, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-13-audio-design.md`

## Global Constraints

- **Nunca `git commit`/merge/push** (regla del usuario). Cada tarea cierra dejando archivos sin `git add` + lista + mensaje propuesto.
- **Nunca descargar DeepFilterNet sin confirmación del usuario** (nombre, origen, ~30 MB).
- Receta de limpieza **sin cambios** respecto a video-cleanup: `highpass=f=80:poles=2`; `deep-filter -D -a 35`; `equalizer=f=220:t=q:w=1.2:g=-2,equalizer=f=3200:t=q:w=1.0:g=2.5,equalizer=f=7000:t=h:w=0.7:g=1.5,acompressor=threshold=-24dB:ratio=3:attack=8:release=150:makeup=2`; `loudnorm I=-14 TP=-1.5 LRA=9` dos pasadas; error si |desfase| > 20 ms.
- Atribución MIT ("Adaptado de video-cleanup, MIT © 2026 Mehdi Ksibi") en la cabecera de cada archivo adaptado.
- Música: ánimos `calm|upbeat|curious|dramatic`; `volume` 0.02–0.4 (def. 0.12); `duck` 0–volume (def. 0.04); ducking baja en 0.15 s, sube en 0.4 s; voz unida si hueco < 0.3 s; fade in 0.5 s, fade out 1 s.
- Control final: corregir si |I + 14| > 1 LU o pico > −1 dBTP.
- Salida de render: `media/output/edited/NOMBRE/NOMBRE_edited.mp4`.
- Mensajes de CLI en español sin tildes en código.

### Task 3: `musicVolume` (ducking puro)

  export const musicVolume: (t: number, spans: {start: number; end: number}[], total: number, opts: MusicOpts) => number;

- [ ] **Step 1: Tests que fallan:**
