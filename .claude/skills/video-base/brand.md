# Marca de la profe (editable)

> Este archivo lo puede editar el usuario. Si algo aquí contradice a una skill, gana este archivo.
> Valores iniciales tomados del video de referencia (`media/reference/Referencia.mp4`) y de `ACTUALLY.mp4`.

## Público
Hispanohablantes que aprenden inglés (nivel básico a intermedio), en TikTok. Llegan por curiosidad; se quedan si el dato es útil y rápido.

## Tono
Cercano, de "te cuento un secreto". Español neutro con el inglés justo. Frases cortas. Nada de tecnicismos gramaticales sin un ejemplo al lado.

## Visual
Estilo `referencia`: serif elegante (Playfair) + crema `#FCF4B0` para lo destacado, sans (Poppins) para subtítulos. Pocos elementos a la vez, bien animados.

## Ganchos (`title`)
- "Sabias que??" / "en inglés"
- "Error que todos cometen" / "en inglés"
- "No digas X" / "di esto"
- "Suena más nativo" / "con esto"
- "¿Cómo se dice…?" / "en inglés"

Elige el que encaje con lo que dice la profe en los primeros segundos. `line1` corta (≤ 14 caracteres), `line2` en cursiva crema.

## Cierres (`end`)
- "¿Te sirvió?" / "¿Qué otro dato conoces?"
- "¿Lo sabías?" / "Cuéntame en comentarios"
- "Guárdalo" / "para practicar después"

Si la profe dice "sígueme para más tips", el cierre empieza ahí.

## Emojis frecuentes
🤫 `1f92b` secreto · 📚 `1f4da` estudio · 😳 `1f633` vergüenza · 🙌 `1f64c` celebración. Otros: `npm run emoji -- <emoji>`.
